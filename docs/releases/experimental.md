# 实验模式

基于上游 v1.4.9，适用于 Windows 10/11 x64。

## 新增功能

- 自动卡厄思实验模式：预设卡组编辑、复制、排序，以及按卡牌名称、效果、神闪和数量选牌。
- 实验模式与普通模式互斥运行；完善指定记忆、商店购买、移除及复制的衔接。
- 预设编辑窗口支持“从卡组码导入”，按本模式的简体／繁体中文设置生成匹配文本。成功后覆盖编辑窗口，保存后生效；取消或失败保留原配置。
- 卡组码支持“抽取1”等短神闪文本和普通附加灵光（如破坏时间轴的士气效果）。本地转换尽量保留可识别卡牌和字段；缺失内容在表格“导入提示”列标出，可双击补填，保存并重新打开后仍保留提示。
- 热门配置上传排除个人预设，应用热门配置时保留本地预设。
- PC 后台截图与 PostMessage 下，窗口移动、缩放、最小化或短暂截图失败进入恢复等待，取得有效画面后继续。恢复前拦截旧坐标输入；手动暂停和停止仍然有效。

## 使用方式

使用包含上述功能的源码或程序包，进入“自动卡厄思模式（实验）”。首次创建会继承普通模式的当前配置，并把旧“闪光优先级”转换为预设记录；之后实验模式配置单独保存。卡组码导入取本模式的“游戏语言”设置，请按游戏客户端选择简体中文或繁体中文。

在“预设卡组”点击“修改”，可手动编辑或选择“从卡组码导入”。导入后检查卡牌数量、效果和“导入提示”，再点击“保存”写入配置。缺失字段可双击对应卡牌补填。

PC 后台运行时选择 `WGC` 或 `BitBlt` 截图、`PostMessage` 交互。窗口状态异常时会等待恢复；手动暂停、停止仍然有效。可选便携包构建见 [打包说明](../../BUILD.md)，其配置保存在 exe 同级的 `configs` 目录。迁移自己的配置时同时复制该目录；构建脚本不内置个人卡组或识别模板。

## 当前限制

- 官方卡组码通过第三方 `cznmetadecks.com` 联网解析，会向该站发送粘贴的代码。含【记忆】等赛季卡的代码可能返回 `unknownCard`；请先在原 BD 中去掉赛季卡，重新导出后再导入。解析失败时保留原预设，不会自动剔除卡牌；不包含离线协议解码器。
- 繁体文本来自游戏静态数据，简体通过 OpenCC 转换。部分地区用词、动态数值或同名变体需要在保存前检查关键字。
- 最小化期间停止识别和点击，等待还原后自动继续；不保证最小化后仍能抓取新画面。持续后台运行可保持窗口打开并由其他窗口覆盖。
- 游戏客户区需为 16:9 且至少 1280×720；移出屏幕、尺寸过小或比例不符时等待恢复。
- 窗口恢复逻辑通过模拟窗口状态及框架集成测试；仍需在实际游戏中验证不同显卡和窗口行为。
